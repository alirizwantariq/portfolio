# assets

Drop your portrait photo here as **`ali-rizwan-tariq.jpg`**.

- Portrait orientation, roughly 3:4 or 4:5. The page crops it to 4:5 and
  focuses near the top of the frame (`object-position: 50% 12%` in styles.css).
- Aim for 800–1200px on the long edge and under ~300KB so the page stays fast.
- If the file is missing the portrait block hides itself automatically —
  nothing breaks.
